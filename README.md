# Isotely

**Category direction under review:** **Equal Treatment. Without Citizenship.**  
**Owner:** Sohadot  
**Branch status:** Strategic pivot proposal; not merged, launched or approved for search indexing.

Isotely is a historically attested word with lineage in Greek *isoteleia*, associated with bounded fiscal equality privileges for certain non-citizens. The proposed contemporary extension examines when legally defined non-citizens receive treatment comparable to citizens **for a specific right or obligation**, without acquiring citizenship itself. The extension is not the classical definition.
